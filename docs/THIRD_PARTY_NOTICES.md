# 第三方资源说明

## Trianon

独立聊天页的信纸纹理与山茶花插画来自 [qimingjiu/Trianon](https://github.com/qimingjiu/Trianon)。雾蓝、奶白、深靛蓝和金色细节，以及信笺式对话布局参考了该项目的洛可可视觉风格；网页的聊天功能和校园内容由本项目实现。
