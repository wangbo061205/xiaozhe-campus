# 已选设计参数在小程序中的应用

选定方案保存在 `design-lab/selected-design.json`，以用户提供的 `campus-design.json`（导出时间 `2026-10-24T11:46:41.495Z`）为基础。2026-10-26 按用户要求柔化了深浅色正文及次要文字，其他选定尺寸和配色保留：浅色、12px 页面边距、12px 区块间距、14px 正文、8px 内容圆角、40px 玻璃圆角，图标底色为 `#D1D6D7`。

在项目根目录运行：

```powershell
npm run design:apply
```

该命令读取已选方案，生成小程序主题、导航变量、JS 配置和图标，并同步系统导航栏及底栏配色。也可使用 `node scripts/apply-design.mjs '完整参数文件路径'` 后运行 `npm run assets`。

生成的参数在 `miniprogram/design-config.json`，运行时通过 `miniprogram/utils/design-config.js` 读取；微信小程序不能直接 require JSON。自定义底栏单独引入 `styles/navigation-tokens.wxss`，以适配它的样式隔离。

首页、地图、AI 助手、失物招领、我的及其子页面使用统一语义颜色、边距和文字层级。内容卡片保持实色，浮动底栏使用半透明材质。主色较浅时，文字采用计算后的深色，避免按钮文字看不清。

地图保留原生地图、真实点位、校区切换、搜索、地点面板和路线操作；面板、控件及导航尺寸按选定参数换算为运行时像素。

`liquid-glass-react` 用于 Web 调参台；微信原生 WXML/WXSS 的玻璃材质为近似实现，不能直接运行 React DOM 的 SVG 折射效果。辅助显示参数可减少透明度及动态效果。

视觉细节集中在 `miniprogram/styles/craft.wxss`：数字使用等宽字形，卡片外圆角由内容圆角加实际内边距派生；标题、图标与列表内容分项短淡入，标题使用平衡换行，多层柔和阴影代替常规外边框。减少动态或低性能模式停用入场动画，高对比度下保留轮廓。对应 Web 材质示例及代码见 `design-lab/REFLECTIVE_CARD.md`，React/WebGL 金属卡片仅用于 Web 预览。

`scripts/verify-design.ps1` 可通过现有微信开发者工具检查 15 页编译、布局边界和真实数据。上一次完整检查使用旧参数；新一轮全页检查遇到本机代理及登录问题而中断。本轮按钮样式已完成独立浏览器的 CSS 解析和优先级检查，仍需在微信环境核对显示。图片功能的单元、集成和浏览器验证见 [LOST_FOUND_IMAGES.md](LOST_FOUND_IMAGES.md)。

2026-10-26 的按钮材质扩展集中在 `styles/craft.wxss` 与独立底栏样式：搜索、发送、发布、提交、图片增删、筛选、分段、地图工具、快捷图标及服务入口使用同一套模糊与饱和度、均匀 10% 白色叠层、1px 内亮边和多层柔和阴影。两侧的静态内阴影近似玻璃折边；原生 WXSS 不会像 Web 的 SVG 位移滤镜那样真实扭曲背景。首页封面改为大块柔和单色，活动及失物照片仍是内容图片。

2026-10-29 按用户要求恢复首页原有校园湖景照片，图片资源沿用 `assets/campus-cover.jpg` 和媒体接口；有图时用白色标题与暗色遮罩，无图时回退为蓝白主题的深字纯色背景。其余按钮材质和蓝白配色继续沿用。

按钮不改变业务节点与事件。选中状态增加字重和下划线；撤销/放弃等动作保留信号色；禁用状态去掉亮边和模糊。低性能模式使用实色与轻阴影，增强对比度使用实色及清晰轮廓，系统减少透明度时关闭模糊和折边。参数关闭透明度时通过导出的填充、模糊与叠层变量降级。本轮仅修改样式，原生效果仍需微信真机验证。
