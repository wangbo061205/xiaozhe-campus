# 课表导入与修改

小程序「校园 → 我的课表 → 导入课表」提供文件、照片、教务系统三种导入方式。所有方式都先预览，可逐条修改或移除，点击「确认导入」才保存。已有课程保留，字段完全一致的课程自动跳过。没有手工新增入口，已有课程可点击后修改或删除。

## 文件导入

从微信聊天选择文件，单个最多10MB：

- Excel（.xlsx / .xls）：支持课程列表，也支持带周一至周日表头、明确节次的网格课表及纵向合并课程块。
- CSV / TSV：支持UTF-8和常见GB18030中文编码。周次含逗号时请用双引号包住整个单元格。
- JSON：支持课程数组或包含 `courses` 的对象。
- ICS：需先设置开学日期；支持单次、每周或隔周重复的课程。起止时间须与第1—8节一致，重复事件须有结束日期或次数。特殊调课和复杂重复规则会提示调整后再导入。
- PDF：支持有文字层的文件，最多10页；扫描版PDF请将课表页保存为图片，使用照片导入。

课程列表的CSV示例：

```csv
课程名称,星期,开始节次,结束节次,教师,教室,周次
大学物理II,周二,1,2,马老师,160212,1-16
数据结构与算法,周四,5,6,纪老师,310110,1-16(双)
```

JSON示例：

```json
{"courses":[{"name":"大学物理II","weekday":2,"startSect":1,"endSect":2,"teacher":"马老师","location":"160212","weeks":"1-16"}]}
```

星期为1—7，节次为1—12。教师、教室、周次允许留空；周次留空表示每周，也支持 `1-16`、`1-16(单)`、`2-16(双)`、`1,3,5`。未知星期、倒置节次、错误周次会明确提示，不会保存一半课程。

## 照片导入

可拍照或从相册选择完整课表，支持JPG/PNG，最多10MB。请保留星期、节次及课程文字，尽量裁去无关内容。照片识别和PDF内容会交给服务端配置的模型结构化，必须核对结果后确认。无法从单周截图判断整个学期的周次时，会提示核对，不把推测的周次当成确定信息。

Windows本地服务使用系统已有中文OCR，再由现有文字模型整理，不依赖浏览器或小程序内保存的模型密钥。原图在服务端临时处理，处理结束清理，不写入公开图片库。高分辨率图片会按系统OCR限制等比缩放。

在Linux/容器或需要视觉识别的环境，配置以下服务端环境变量后重启后端：

```text
COURSE_VISION_BASE_URL=https://兼容OpenAI接口的服务地址/v1
COURSE_VISION_API_KEY=由部署者填写
COURSE_VISION_MODEL=支持图片输入的模型名称
```

不支持照片识别的运行环境会明确提示使用Excel或教务系统，不会返回伪造课程。

## 教务系统

先在「关联或管理教务账号」使用现有授权码/账号流程绑定，再点「教务系统」读取当前学期课程。请求使用当前设备的访客身份关联，不接受客户端自报的他人身份。需上游教务服务和已关联账号真实可用；没有授权时会保留错误说明并提供关联入口。

## 周视图与上课时间

在右上角设置本学期开学日期，所在周按第1周计算。切换周次时按单双周和指定周次筛选；「显示非本周课程」可查看淡色标记的完整学期。未设置开学日期时展示全部课程，并提示先设置日期。遇到同一天节次重叠，会并排显示并标记。

| 节次 | 开始 | 结束 |
| --- | --- | --- |
| 1 | 08:00 | 08:45 |
| 2 | 08:55 | 09:40 |
| 3 | 10:10 | 10:55 |
| 4 | 11:05 | 11:50 |
| 5 | 14:00 | 14:45 |
| 6 | 14:55 | 15:40 |
| 7 | 16:10 | 16:55 |
| 8 | 17:05 | 17:50 |

第9—12节可保存和显示，尚无校方确认时间，页面只显示节次，不编造时间。

后端新增迁移 `V7__course_timetable_settings.sql` 保存每个用户的开学日期；升级保留原课程。新接口位于 `/api/v1/courses/settings`、`/import/preview`、`/import/education`、`/import/confirm`，课程修改使用 `PUT /api/v1/courses/{id}`，都要求设备会话。
