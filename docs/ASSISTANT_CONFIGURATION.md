# AI 首页与后台配置

小程序默认进入 AI 助手。底栏依次为“小折、校园、地图、失物招领、我的”；“校园”保留原来的湖景封面、服务入口和校园动态。用户无需手工登录，聊天使用独立的设备访客会话。独立网页机器人可通过同一服务地址的 `/xiaozhe.html` 打开，也使用自动访客会话。

## 设置人设和欢迎内容

使用管理员账号访问 `http://127.0.0.1:8080/`，打开“AI 助手设置”：

1. 设置助手名称、欢迎语和开场建议。默认名称为“小折”，小程序与独立网页共用此设置。
2. 在角色设定中填写身份定位、语言习惯、回答长度和希望关注的内容。例如：“你是温和、耐心的校园伙伴，先理解同学的感受，再一起找一个能开始的小步骤。每次只问一个问题，不说空泛的大道理。”
3. 按需要启用知识库回答和温柔陪伴。
4. 如需提供学校心理支持渠道，填写已核实的联系信息及核实日期；没有可靠信息时留空。
5. 保存后，后续消息使用新设置。重新进入聊天页时更新名称、欢迎语和建议，已有用户对话不会被欢迎语覆盖。

配置保存在服务端数据库中，重启服务后继续保留，修改人设无需重新打包小程序。后台仅向管理员开放助手设置，不提供用户私聊查看入口。

## 维护知识库

在“知识库”中新建或编辑条目，填写标题、正文、类型和内容来源。常见问答可使用“常见问题”，校园手续可使用“办事指南”。

“保存待发布”用于准备内容；“保存并发布”后，开启知识库回答的 AI 助手才会检索到该内容。下架后不再用于后续检索。回答引用条目时，小程序显示可点击的来源。

请将校内时间、地点、费用、联系方式等信息写清楚并标注来源。知识条目用于提供资料，人设用于定义语气和表达方式，分别在对应页面维护。

## 情绪陪伴

默认以倾听、接纳和不评判的方式交流，帮助用户描述感受并寻找可行的小步骤。助手保持 AI 身份，不作心理诊断、用药指导或治疗承诺。出现明确的自伤危险时，优先提供即时安全支持和可信的现实联系渠道；未配置的电话号码不会凭空生成。

模型暂不可用时，会明确提示并保留重试入口；校园信息也可以通过“校园”中的搜索查看。聊天上下文目前仅保存在后端内存中，服务重启后从新对话开始。

## 接口约定

- `GET /api/v1/config/public`：公开名称、欢迎语、开场建议及陪伴开关，不公开人设提示或后台联系配置。
- `GET /api/v1/admin/assistant-settings`：管理员读取当前设置。
- `PUT /api/v1/admin/assistant-settings`：管理员保存设置。
- `POST /api/v1/chat`、`POST /api/v1/chat/reset`：使用自动访客身份，对话按用户隔离。

助手设置包含 `name`、`greeting`、`personaPrompt`、`suggestions`、`knowledgeEnabled`、`emotionalSupportEnabled`、`supportContact` 和 `supportContactVerifiedAt`。联系方式为空时核实日期也应留空；填写时应提供有效核实日期。
