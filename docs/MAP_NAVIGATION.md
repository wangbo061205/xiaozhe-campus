# 校园地图与手动选点路线

## 使用方式

1. 打开地图先看到校园全览，通过搜索、推荐地点或分类选择目的地。
2. 点击“选择出发地点”，从当前校区的已标注地点中选择起点；也可长按地图设置起点。
3. 点击唯一的“出发”按钮，查看校园道路路线、距离、预计用时和路线说明。视野同时包含校园边界、起终点及完整路线。
4. 修改起点或目的地后清除旧路线，再点击“出发”规划。切换校区会重置起点。

## 无定位接口版本

小程序不获取设备位置，不启动前台或后台定位，不显示设备位置蓝点，也不调用微信地图打开位置接口。`app.json` 不声明 `scope.userLocation`、`requiredPrivateInfos` 或后台定位模式。校园地点和路线使用公开点位与用户手动选择的坐标，因此不依赖微信地理位置接口的申请结果。

此版本提供手动选点的参考路线，不提供当前位置跟随或每 5 秒实时更新。长按地图获得的是用户指定的地图坐标，不是设备位置。手动起点只保存在当前页面内存，不写入校园数据缓存。

微信正常的代码审核、服务器合法域名和第三方校园数据服务配置仍需按实际部署设置。移除位置接口并不替代这些配置。

## 服务不可用时

使用内置或已保存的真实校园点位继续浏览、分类和搜索。底图及校园道路规划需要网络；路线请求失败会保留起终点并显示重试提示，不绘制虚构路线，不跳转到其他需要位置接口的流程。服务恢复后可再次点击“出发”。

## 验证

Node 测试覆盖手动起点、长按选点、坐标校准、完整视野、重复点击、取消及迟到请求、校区切换和断网重试；同时检查发布目录不存在私密位置接口调用或权限声明。
