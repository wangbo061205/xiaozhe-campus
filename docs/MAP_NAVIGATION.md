# 校园目的地与第三方导航

## 用户操作

1. 在校园地图里搜索或浏览地点，选中目的地。
2. 点击唯一的“出发”按钮，打开微信内置地图的目的地详情。
3. 在该地图页点击“导航”，选择手机上可用的导航应用，例如高德、百度或腾讯地图。

可选应用以微信版本、手机系统和已安装的地图为准，小程序无法指定系统弹窗中一定出现哪些应用，也不能绕过微信直接任意启动原生 App。页面另提供“复制地点”作为兼容操作。

## 实现和隐私

仅调用 `wx.openLocation`，传入公开目的地的 GCJ-02 经纬度、名称和地址。此 API 用于展示已知目的地，不获取用户当前位置；微信官方的 `requiredPrivateInfos` 八项位置接口列表中不包含它。地图应用会自行管理其定位授权和路线规划。

小程序不调用 `getLocation`、模糊定位、持续定位、位置选择、地址获取或地图插件，不声明 `scope.userLocation`、`requiredPrivateInfos` 或后台定位模式；不再让用户选择起点，不再请求 `road.plan`，也不显示虚构的距离或到达状态。后端原有校园路线 API 可供其他用途，但这个客户端导航流程不依赖它。

使用已有点位和地图校准结果保持地图标记与传入目的地一致。返回小程序后保留目的地，可再次出发；跳转取消、失败或用户换地点时不会被迟到回调覆盖。

## 服务暂不可用

内置或已保存的真实校园地点仍可分类、搜索和交给微信地图导航。更新校园资料仍需后端，地图底图及导航应用的正常运行仍需要网络。没有坐标的地点不会启动导航，可复制名称到地图应用搜索。

## 验证与平台依据

Node 测试覆盖只传目的地、离线点位、校准、重复点击、缺失坐标、失败重试、取消、复制以及切页时的迟到回调；发布目录检查继续禁止获取设备位置的接口。WXML / WXSS 通过后，还需手机实测微信导航菜单和已安装地图的跳转；模拟器不能证明高德、百度、腾讯 App 的真机行为。

- 配置说明：[requiredPrivateInfos](https://developers.weixin.qq.com/miniprogram/dev/reference/configuration/app.html#requiredPrivateInfos)
