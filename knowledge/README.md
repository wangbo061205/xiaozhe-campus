# 知识库数据说明

`official-knowledge.csv.gz` 是本部署包的校园知识种子数据，首次启动由 `knowledge-seed` 容器自动导入 PostgreSQL。

- 数据条数：8,811 条，全部为 `PUBLISHED`；
- 内容类型：通知 8,730、部门 19、政策 51、指南 5、常见问题 6；
- 数据字段：标题、正文、摘要、官方原文链接、来源站点、原栏目、原始发布日期及导入标识；
- 日期未知：166 条，保留为空，不用导入日期冒充原始发布日期；
- 内容可能不完整：661 条，可能是简短页面、图片或附件型内容，回答时仍应提示核验原文；
- 去重方式：`import_key` 唯一，重复启动不会覆盖管理员后续修改；
- 数据快照：来源抓取于 2026-10-30，部署后应由管理员持续审核时效。

本包只导出带 `nmu-official:` 标记的官方资料。未包含 19 条本地演示条目，也未包含用户、访客密钥、聊天、失物记录、模型调用记录、审计日志或上传图片。

`export-official-knowledge.sql` 记录了本次导出范围；`source-import-report.json` 是数量核验报告；`manifest.json` 记录文件摘要。校园资料保留原文链接，不代表部署者拥有原文版权，公开使用前应按来源网站规则核对。
